# VS Code Keyboard Shortcuts for Windows

This note lists common Visual Studio Code shortcuts specifically for Windows.

| Shortcut | Command | Description |
|---|---|---|
| `Ctrl+Shift+P` / `F1` | Command Palette | Run VS Code commands by name |
| `Ctrl+P` | Quick Open | Open files quickly |
| `Ctrl+Shift+N` | New Window | Open a new VS Code window |
| `Ctrl+Shift+W` | Close Window | Close the current VS Code window |
| `Ctrl+` ` | Toggle Terminal | Show/hide integrated terminal |
| `Ctrl+B` | Toggle Side Bar Visibility | Show/hide the side bar |
| `Ctrl+Shift+E` | Show Explorer | Open the Explorer view |
| `Ctrl+Shift+F` | Search | Search across workspace files |
| `Ctrl+Shift+H` | Replace | Replace text across files |
| `Ctrl+` `[` / `Ctrl+` `]` | Indent / Outdent | Adjust selected code indentation |
| `Alt+Up` / `Alt+Down` | Move Line Up/Down | Move lines of code |
| `Ctrl+D` | Add Selection to Next Find Match | Create additional cursors |
| `Ctrl+K Ctrl+S` | Keyboard Shortcuts | Open shortcut editor |
| `F8` | Next Problem | Navigate problems in the editor |
| `Ctrl+Shift+M` | Problems Panel | Open problem diagnostics |
| `Ctrl+Shift+D` | Run and Debug | Open debugger view |
| `F5` | Start Debugging | Run current debug configuration |
| `Ctrl+K Z` | Zen Mode | Enter distraction-free mode |
| `Ctrl+,` | Settings | Open VS Code settings |
| `Ctrl+K Ctrl+T` | Change Theme | Select a color theme |
| `Ctrl+K Ctrl+X` | Trim Trailing Whitespace | Remove trailing spaces |

> These shortcuts are tailored for Windows and match the default keymap in Visual Studio Code.
