# VS Code Commands Reference

This note documents common Visual Studio Code commands in a tabular format.

| Command | Description | Use Case |
|---|---|---|
| `Ctrl+Shift+P` / `F1` | Open the Command Palette | Run any VS Code command by name |
| `Ctrl+P` | Quick Open file | Open files by path or filename |
| `Ctrl+Shift+N` | New Window | Open a new VS Code window |
| `Ctrl+Shift+W` | Close Window | Close the current VS Code window |
| `Ctrl+` ` | Toggle Terminal | Show or hide the integrated terminal |
| `Ctrl+B` | Toggle Side Bar visibility | Hide or show the Explorer/side bar |
| `Ctrl+Shift+E` | Show Explorer | Open the file explorer view |
| `Ctrl+Shift+F` | Search across files | Search text in the workspace |
| `Ctrl+Shift+H` | Replace across files | Search and replace across workspace files |
| `Ctrl+` `[` / `Ctrl+` `]` | Indent/outdent lines | Adjust indentation of selected code |
| `Alt+Up` / `Alt+Down` | Move line up/down | Reorder lines or blocks of code |
| `Ctrl+D` | Add selection to next find match | Multi-cursor selection |
| `Ctrl+K Ctrl+S` | Keyboard Shortcuts reference | Open the keyboard shortcut editor |
| `F8` | Go to next problem | Jump to the next error or warning |
| `Ctrl+Shift+M` | Problems panel | Open the Problems view for build/lint issues |
| `Ctrl+Shift+D` | Run and Debug | Open the Run and Debug view |
| `F5` | Start debugging | Begin debugging the current launch configuration |
| `Ctrl+K Z` | Zen Mode | Enter distraction-free mode |
| `Ctrl+` `,` | Open Settings | Open VS Code settings UI |
| `Ctrl+K Ctrl+T` | Change Theme | Open color theme picker |
| `Ctrl+K Ctrl+X` | Trim trailing whitespace | Remove trailing spaces in the file |

> Note: Commands in this list are the core VS Code commands shared across most platforms. For Windows-specific shortcuts, see the separate Windows commands note.
