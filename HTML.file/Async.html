Research Note: async Keyword

The async keyword is used to define asynchronous functions, allowing non-blocking operations (like network calls, file I/O, and timers) while keeping code readable with await.

JavaScript

What it does

  • An async function always returns a Promise.
  • await pauses execution inside that async function until a Promise settles.
  • Errors are handled with try/catch around await calls.

Example

async function fetchUser(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    if (!response.ok) throw new Error("Failed to fetch user");
    return await response.json();
  } catch (err) {
    console.error(err);
    throw err;
  }
}

Python

What it does

  • async def defines a coroutine function.
  • await waits for an awaitable object inside an async function.
  • Typically used with an event loop (asyncio).

Example

import asyncio

async def fetch_data():
    await asyncio.sleep(1)
    return "done"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())

Benefits

  • Improves responsiveness in I/O-heavy tasks.
  • Reduces callback nesting and improves readability.
  • Supports concurrent workflows when combined with Promise/task utilities.

Common Pitfalls

  • Forgetting to await a Promise/coroutine can cause unexpected behavior.
  • Using CPU-heavy work in async code still blocks unless offloaded.
  • Unhandled rejections/exceptions can terminate flows silently if not surfaced.
