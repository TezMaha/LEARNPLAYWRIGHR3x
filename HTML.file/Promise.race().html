Research Note: Promise.race()

Promise.race() returns a promise that settles as soon as the first input promise settles, whether it resolves or rejects.

How it works

  • Accepts an iterable (usually an array) of promises.
  • The earliest settled promise decides the result.
  • If the first settled promise resolves, Promise.race() resolves.
  • If the first settled promise rejects, Promise.race() rejects.

Example

function timeout(ms) {
  return new Promise((_, reject) =>
    setTimeout(() => reject(new Error("Request timed out")), ms)
  );
}

async function fetchWithTimeout(url, ms = 3000) {
  const response = await Promise.race([
    fetch(url),
    timeout(ms)
  ]);
  return response.json();
}

Benefits

  • Useful for implementing request timeouts.
  • Helps choose the fastest source among multiple async options.
  • Supports responsive fallback strategies.

Common Pitfalls

  • Loser promises still continue running unless canceled separately.
  • A fast rejection can fail the whole race even if success would arrive shortly.
  • Not suitable when you need all results; use Promise.all() instead.

When to use

  • Adding timeout behavior to API calls.
  • Competing mirrored services and taking the first response.
  • Selecting quickest cached vs remote data source.
