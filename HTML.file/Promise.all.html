Research Note: Promise.all()

Promise.all() is a JavaScript method that runs multiple promises concurrently and resolves when all of them succeed, returning results in the same input order.

How it works

  • Takes an iterable (usually an array) of promises.
  • Resolves once every promise resolves.
  • Rejects immediately if any one promise rejects.
  • Result order matches the input promise order, not completion order.

Example

async function loadDashboard() {
  try {
    const [user, posts, notifications] = await Promise.all([
      fetch("/api/user").then(r => r.json()),
      fetch("/api/posts").then(r => r.json()),
      fetch("/api/notifications").then(r => r.json())
    ]);

    return { user, posts, notifications };
  } catch (error) {
    console.error("Failed to load dashboard data:", error);
    throw error;
  }
}

Benefits

  • Improves performance by executing independent async tasks in parallel.
  • Reduces total wait time compared to awaiting each task sequentially.
  • Provides a clean pattern for combining multiple async results.

Common Pitfalls

  • If one promise fails, the entire Promise.all() fails.
  • Not ideal when you need partial success handling; use Promise.allSettled() then.
  • Launching too many heavy operations at once can overwhelm APIs or resources.

When to use

  • Fetching several independent endpoints for one page load.
  • Running parallel file/network/database operations where all must succeed.
  • Combining related async data before rendering or processing.
