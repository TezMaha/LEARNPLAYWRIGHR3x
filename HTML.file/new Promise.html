Research Note: new Promise

new Promise() creates a Promise manually in JavaScript. It is useful when wrapping callback-based APIs or custom asynchronous operations into Promise-based flows.

How it works

  • Syntax: new Promise((resolve, reject) => { ... }).
  • Call resolve(value) when the async task succeeds.
  • Call reject(error) when the async task fails.
  • A Promise can settle only once: resolved or rejected.

Example

function wait(ms) {
  return new Promise((resolve) => {
    setTimeout(() => resolve(`Done after ${ms}ms`), ms);
  });
}

wait(1000)
  .then(console.log)
  .catch(console.error);

Benefits

  • Converts old callback-style code into modern Promise chains.
  • Works naturally with .then(), .catch(), and async/await.
  • Improves readability and error propagation in async flows.

Common Pitfalls

  • Forgetting to call resolve or reject causes pending promises forever.
  • Throwing inside executor without handling can reject unexpectedly.
  • Overusing manual promises where built-in Promise APIs already exist.

When to use

  • Wrapping callback APIs such as timers, file reads, or legacy SDK methods.
  • Building custom async utilities with explicit success/failure control.
  • Integrating non-Promise asynchronous code into async/await workflows.
